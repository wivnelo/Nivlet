# Nivlet 发布与推广用语

适用正式版本：2.0.2 / Build 62。

## 简短介绍

Nivlet 是免费开源的 macOS 桌面工具箱，提供窗口布局、文字与图片剪贴板历史、应用快捷启动、按应用切换输入法、浏览器分流和菜单栏系统信息。无需账号，核心功能在本机运行。

2.0.2 减少菜单栏和剪贴板的后台开销，功能不变。2.0.1 增加保持唤醒与保持屏幕长亮、统一浏览器图标并支持打开 Brave 清理确认框，移除 MAC 地址展示；保留八页设置及四语言。新版本仅支持 Apple Silicon（arm64）与 macOS 13+；[1.0.8 / Build 55](https://github.com/wivnelo/Nivlet/releases/tag/v1.0.8) 是最后 Intel 版，历史下载保留。

- 官网：https://wivnelo.github.io/Nivlet/

## 对外说明边界

- 仅在最终 App 和 DMG 实际通过后写“Developer ID 签名、Apple 公证”；不写“Apple 官方认证”“绝对安全”或“上架 App Store”。
- 新版不支持 Intel，也不宣称 Intel 真机测试；保留历史包不等于继续支持后续版本。
- 繁中采用台湾用语，香港环境回退到繁中；不宣传独立港式本地化或母语人工审校。
- 不把本地 HTML/HTM 描述为任意文件/协议支持，不把跨模块运行时保存描述为完整原子事务。
- 精简收益必须引用最终同架构包的实测值，不能把不再提供 Intel 包说成 ARM 安装包缩小一半。
- 公证不代替辅助功能授权。配置、剪贴板及系统信息在本机处理；检查更新、下载和打开网站会联网；可选持久历史使用本地明文缓存。
- 截图使用合成数据；私钥、公证凭据、私人配置和历史不进入公开产物。

## English

Nivlet is a free, open-source macOS toolkit for windows, clipboard history, app shortcuts, input switching, browser routing and menu-bar system information. Version 2.0.1 adds optional Keep awake and Keep display on switches, shared browser icons and the Brave clear-data confirmation entry, and removes the MAC address display. New versions support Apple Silicon (arm64), macOS 13+ only. Version 1.0.8 Build 55 remains the final Intel release, with historical downloads retained.
