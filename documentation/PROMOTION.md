# Nivlet 正式发布与推广用语

适用版本：1.0.7 / Build 53。

## 简短介绍

Nivlet 是一款从日常自用需求慢慢整理出来的 macOS 桌面工具箱：窗口布局、文字与图片剪贴板历史、应用快捷启动、按应用切换输入法、浏览器分流，以及菜单栏网速与系统信息。免费开源，无需账号，核心功能在本机运行。

目前已启用 Apple Developer ID 正式签名并通过 Apple 公证，提供 Apple Silicon 与 Intel 安装包，支持 macOS 13+。欢迎试用，有用的话欢迎 Star，问题和建议欢迎提 Issue。

- 官网：https://wivnelo.github.io/Nivlet/
- 源码：https://github.com/wivnelo/Nivlet
- 下载：https://github.com/wivnelo/Nivlet/releases/tag/v1.0.7
- 反馈：https://github.com/wivnelo/Nivlet/issues

## 对外说明边界

- 可说“Developer ID 签名、Apple 公证”；不要写“Apple 官方认证”“绝对安全”或“已上架 App Store”。
- 公证不代替辅助功能授权。旧 ad-hoc 版首次迁移可能需要重新授权，后续稳定签名更新通常沿用；不要承诺所有系统永远免授权。
- 配置、剪贴板和系统信息本机处理；检查更新、下载与打开网站会联网。跨重启剪贴板历史是可选的本地明文缓存。
- 签名详情公开开发者证书姓名与 Team ID；公开说明不必重复证书个人信息。私钥、公证密码不进入源码、文档或知识库。
- 推广截图继续使用虚构内容，避免私人应用列表、剪贴板、地址、账户与邮件。

## English

Nivlet is a free, open-source, local-first macOS toolkit for window management, clipboard history, app shortcuts, input switching, browser routing and menu-bar system information. No account required. Now Developer ID signed and Apple notarized, with Apple Silicon and Intel downloads for macOS 13+. Stars, issues and suggestions are welcome.
