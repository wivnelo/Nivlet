## English

- Show a red “(Not installed)” indicator directly after the app name, with localized parentheses and text.
- Support Apple Silicon and Intel updates with the matching signed architecture package.

Requires macOS 13+. Ad-hoc signing; no Developer ID signature or Apple notarization.
