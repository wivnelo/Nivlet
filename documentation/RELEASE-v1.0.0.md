# Nivlet 1.0.0 · Build 32

首个推广正式版，Apple Silicon / macOS 13.0+。

- 窗口布局、应用快捷启动、按应用切换输入法。
- 域名与来源应用浏览器分流。
- 剪贴板文本/图片历史、暂停、排除应用与可选本地持久化。
- 系统信息、中英双语、深浅色与配置导入导出。
- 手动确认签名更新，发行物隐私检查与中性路径干净构建。

使用 ad-hoc 签名，**没有 Apple Developer ID 签名或公证**。请阅读[首次安装指南](INSTALLATION.md)。不支持 Intel；其他机器和所有第三方输入法尚未全面验证。个人配置与剪贴板历史不会随安装包分发。
