# A 版界面、本地 HTML 与全局保存

本轮范围由用户明确选定：采用系统设置式左侧栏统一八个页面；修复本地 `.html/.htm` 打开；将保存按钮改为保存所有有修改的页面。其余业务与安全边界保持不变。

## 实施边界

- 保留 HTML/CSS/JavaScript WebView 与 Lua 模块；不迁移到 SwiftUI，不改配置格式、菜单栏功能或应用安装状态。
- 共用侧栏、分组卡片、控件尺度、焦点、错误与草稿样式；通用固定首位、关于固定末位，中间六项排序仍即时保存。纵向导航增加上下键，保留左右键及 Home/End。
- 保留 980×720 初始尺寸；内容区域独立滚动，保存栏固定。宽窗剪贴板双栏，小窗改为同一页面纵向滚动，所有控制仍可到达。
- 全局保存只提交有改动的页面，先验证完整候选；未改动页不覆盖。保存期间冻结编辑并匹配批次回执。成功页与失败/待处理页分别反馈；系统操作与剪贴板清理不宣称具有跨模块原子事务。
- 本地 HTML 使用已配置的兜底浏览器，明确指定浏览器应用，避免重新进入 Nivlet；HTTP(S) 的域名/来源规则不变。不更改系统文件关联、默认浏览器、权限或安全设置，也不放开任意 URL scheme。
- 不安装替换用户应用，不推送远端或发布，不改签名与权限；历史构建清理另行只读盘点，不在本轮删除。

## 隔离 UI 回归

`scripts/test-settings-ui.cjs` 在独立临时浏览器中读取实际设置 HTML，消息桥为空函数，数据全部为演示值。它不连接 Nivlet 后端、读取用户配置或打开外部网页。需要 Node.js、Lua、Playwright，以及已安装的 Chrome；可以通过 `--browser` 指定现有可执行文件，不自动下载浏览器。

```sh
node scripts/test-settings-ui.cjs --suite all --screenshots --width 980 --height 720
node scripts/test-settings-ui.cjs --suite layout_ui.js,tabs_ui.js --screenshots --width 980 --height 720 --language en --theme dark
node scripts/test-settings-ui.cjs --suite layout_ui.js,tabs_ui.js --screenshots --width 760 --height 640
```

默认输出到忽略目录 `build/ui-regression/`；多轮核验请用 `--out` 指定独立目录。浏览器验证不能替代真实 macOS WebView、系统文件派发、快捷键注册或签名包验收。

## 需覆盖的回归

八页与原入口、侧栏顺序/键盘/草稿标记、中文/英文和深浅色、缩窗/长规则列表、剪贴板滚动与图片预览、权限各状态；跨页一次保存、干净页及关于页发起保存、⌘S、关闭保护、失败与重试、跨模块快捷键交换、未改动页不写；本地 HTML 的特殊字符、大小写、非法/远程 URL、非普通文件、冷启动派发及原 HTTP(S) 规则。

## 本轮验证结果（2026-11-01）

- 29 个 Lua 测试通过，覆盖现有模块和新增本地 HTML、批保存协调、真实模块的内存运行测试。全局保存覆盖跨模块快捷键交换、完整预检零写入、只写脏页、部分成功、失败恢复、登录项入口、关闭/退出协调、系统信息在写入后发生原生菜单异常。
- 27 个隔离 UI 测试和默认 980×720 下八页布局检查全部通过；760×640、1280×900 下布局/侧栏/全局保存，以及 980×720 英文深色布局/侧栏检查通过。截图使用实际设置 HTML 与合成数据；不是已安装应用截图。
- 协调器、快捷键录入、启动项替换、关闭保护、侧栏排序的五个独立 JavaScript 检查通过。Foundation 原生测试确认空格、中文、`#`、`?`、`%` 文件名和 HTML 扩展名大小写正确；旧 URL-only、Dock 行为、bundle 本地化、entitlements 检查通过。
- 隐私回归与源码扫描通过；保留既有签名、权限及 Git noreply 身份要求。测试 harness 本轮使用 Playwright 1.64.1 与系统已安装 Chrome，工具依赖不加入应用运行包。
- 两条原有 UI 测试的过期假设已核实并修正：拖拽前先使被拖行可见，重复应用反馈检查现有底部提示与行高亮。保存相关断言按新批量协议更新，继续检查失败草稿、规则顺序与当前页取消范围。

## 尚需原生候选包验收

后续已按官方隔离 Release 流程完成 arm64 整包编译（Xcode 27.2，1.0.8 / Build55），24 个 Toolkit 源文件一致，101 个 Mach-O 的架构及主程序/dSYM UUID 匹配，隐私扫描通过。安装候选使用原有 Developer ID 身份与审核过的 entitlement，严格签名校验通过；Gatekeeper 返回 `rejected: source=Unnotarized Developer ID`，因此未替换或启动新应用，也未绕过系统保护。真实 macOS WebView、Finder 到实际浏览器、本机跨页持久化与 Intel 验收仍待公证和安装边界解决后进行。详细构建和校验记录在本地忽略目录 `build/native-compile/`。

全局保存是有预检和恢复尝试的协调批次，不是跨模块原子事务。已成功的独立页面在后续失败时保持已保存；失败页保留草稿并使用模块报告的当前配置作为取消基线。`current` 仅表示模块内存配置，不证明原生菜单、快捷键、登录项与磁盘持久化已完全一致。恢复不完整会明确提示并保留重试入口；剪贴板保留策略已经清理的内容无法恢复。
