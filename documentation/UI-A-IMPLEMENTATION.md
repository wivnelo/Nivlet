# 1.0.9 / Build 56：界面、保存与剪贴板调整

当前源码面向 Apple Silicon 正式版。最终构建、公证、实机验收和发布状态以本轮最终记录为准；此前本地 1.0.8 / Build 55 UI 候选的公证与运行结果不能替代本版验证。

## 最终范围

- 保留 WebView 与 Lua 技术栈，用左侧导航、右侧内容统一八个页面。通用固定首位、关于固定末位，中间六项排序仍即时保存；键盘导航、独立内容滚动与草稿标记保留。
- 深色表面颜色依据提供的 macOS 设置截图取样：内容底色 `#1f1e20`、卡片 `#262527`、分隔线 `#302f31`、选中态 `#007aff`。侧栏匹配截图的轻微色差；这是固定截图配色，不是随壁纸变化的系统材质。保留浅色主题。
- 保存全部有改动的页面，先校验完整候选；未改动页不覆盖。保存期间冻结编辑并匹配批次回执，失败保留草稿。取消只恢复当前页配置，保留最新语言、运行时列表和其他页草稿。
- 保存反馈与按钮共用稳定底栏。未保存、保存中、保存成功时按钮位置不变；长错误保留完整文本，可滚动与键盘聚焦查看。
- 本地 `.html/.htm` 通过明确指定的兜底浏览器打开，避免回到 Nivlet 自身；原 HTTP(S) 域名与来源应用规则不变。
- 支持简中、英文、台湾用语繁中和日语。Toolkit 跟随系统或应用内选择；原生菜单按 macOS 启动语言选择资源。应用内选择不会强制 AppKit、Sparkle 的系统界面立即换语言。翻译经过独立 AI 语境与像素审阅，没有声称真人母语校对。
- 剪贴板菜单快捷键改为固定 `⌘⇧V` 的启用开关。缺失配置默认启用，明确关闭持久保存；旧自定义组合保持只读原值，实际操作该开关并保存后才改为固定组合。其他模块的快捷键仍可编辑，冲突不抢占。
- 剪贴板记录只保留总开关，移除独立暂停/恢复。关闭停止采集而不清空历史；期限与应用排除保持。仅在有待过期历史时安排清理计时器，清理不读取新剪贴板内容。
- 移除主图标开关下指定辅助说明，以及剪贴板使用说明块；保留图标开关、历史、复制、Option 粘贴及隐私排除功能。
- 图片放大预览移除可见关闭按钮；点击 Nivlet 窗口内图片元素框外关闭，框内透明区域不误关。保留 Esc、焦点恢复及模态拦截，不监听窗口外全局鼠标。
- 正式发行仅 arm64。仅裁剪框架开发头文件与模块声明，保留运行组件、必要资源和许可证；1.0.8 Build 55 为最后 Intel 版本，历史发行资产保留。

## 保存与迁移边界

全局保存是有预检和恢复尝试的协调批次，不是跨模块原子事务。已成功的独立页面在后续失败时保持已保存；失败页保留草稿并采用模块报告的当前配置作为取消基线。恢复不完整须明确报告；保留策略已经清理的内容不可恢复。

快捷键持久化区分缺省、明确关闭和已保存组合。修改无关设置不得把默认注册暂时失败误记为用户关闭，也不得静默迁移旧自定义组合。启用固定组合仍经过系统、窗口及应用启动快捷键冲突检查。

旧版暂停仅为进程内存状态，没有写入配置。新进程无法推断已经消失的旧状态。本机替换前须检查旧 App：若正在暂停，先关闭总开关并保存，再退出。存在明确旧 `paused: true` 持久字段时按关闭迁移；迁移写入失败也不恢复采集。JSON 导入仍遵循其明确字段校验，不宣称接受任意旧快照。

## 回归与验收

`scripts/test-settings-ui.cjs` 在临时浏览器上下文中读取真实 HTML，使用空消息桥及合成数据，不连接用户配置或个人浏览器资料。它覆盖四语言、深浅色、八页、窄窗、底栏状态、快捷键开关、图片内外点击与键盘行为。隔离浏览器验证不等同于真实 macOS WebView、系统文件派发或原生快捷键注册。

```sh
node scripts/test-settings-ui.cjs --suite all --screenshots --width 980 --height 720 --out build/ui-final
node scripts/test-settings-ui.cjs --suite all --screenshots --width 760 --height 640 --theme dark --out build/ui-final-narrow
```

最终门槛包括：Lua 与原生边界回归、完整 UI 套件、独立审阅、四语言像素检查、隐私扫描、arm64 干净编译、源资源一致性、Developer ID 签名、Apple 公证与票据、Gatekeeper、本机受控验收、更新签名及 Intel 筛选、发布后 tag/commit/资产校验。未完成的实机项目必须单列，不能用模拟测试冒称端到端通过。

## 浏览器明确边界

HTTP/HTTPS 链接不按 PDF、图片等后缀限制。本地文件只明确支持 HTML/HTM；本地 PDF/TXT/图片、`.url/.webloc` 未作完整支持承诺。`file:` 仅接受本机普通可读文件，远程 host、目录、特殊文件等被拒绝。`mailto:`、`tel:` 和应用专属协议应由其系统处理程序负责；`javascript:`、`data:`、`blob:` 不开放外部转交。

异常 query 百分号解码已增加空值保护，完整 URL 保持不变。原生文档类型声明仍比本地 HTML 实现范围宽，冷启动单个暂存事件槽也存在多事件覆盖的既有边界；本轮不扩展文件类型或改为通用协议转发器。Finder 派发、冷启动多文件以及具体浏览器链路需按实际测试结果分别陈述。
