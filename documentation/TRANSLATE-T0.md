# 翻译 · T0 技术验证记录

2026-11-18。目的：在开发选词翻译和截图翻译前，确认只用系统翻译的技术路线可行。方案见翻译方案页（私有 Artifact），探针代码在 `build/t0-translate/`（不进版本库）。

## 环境

- macOS 27.2.1，Apple Silicon；Xcode 27.2
- 探针以后台程序（不显示程序坞图标）运行，和 Nivlet 截图组件相同

## 结果

### 系统翻译调用

| 路线 | 适用系统 | 结果 |
| --- | --- | --- |
| 直接创建翻译会话 `TranslationSession(installedSource:target:)` | macOS 26+ | 后台程序可用。英→中首句 2.5 s、再次 0.9 s；中→英 1.2 s / 1.1 s；日→中 0.6 s / 0.5 s |
| SwiftUI `.translationTask` 挂在不可见窗口 | macOS 15–25（26+ 也可用） | 后台程序可用，英→中首句 2.3 s |

译文质量（示例）：
- “Once a language is downloaded, people can translate text even when they are offline.” → “一旦下载了一门语言，人们即使在离线的情况下也可以翻译文本。”
- “截图只在本机处理，不上传。” → “Screenshots are processed only on the device and are not uploaded.”
- “振込手数料はお客様のご負担となります。” → “汇款手续费由客户承担。”

结论：两条路线都放在截图组件里实现。macOS 26+ 用直接会话；macOS 15–25 用不可见窗口承载 SwiftUI 翻译任务。每次翻译 0.5–2.5 s，窗口需要“正在翻译”状态。

### 语言包

- 系统支持 47 种翻译语言（方案里“约 20 种”不准确，已更正）。
- 本机译成简体中文的语言包已全部下载；只有繁体中文（台湾、香港）到简体中文显示为不支持（同语种转换）。
- 因此**无法在本机触发“语言包下载提示”**，后台程序里下载提示能否正常弹出仍未验证，需要在缺语言包的环境测试；实现时对“未下载”状态给出“前往系统设置下载”的说明作为兜底。

### 自动翻译方向

系统翻译接口不返回原文语言，需要自己判断。用系统自带的 NaturalLanguage 语言识别：

| 文本 | 识别结果 |
| --- | --- |
| 设置 | zh-Hans（1.00） |
| Settings | en（0.33，次选 sv） |
| 設定を保存しました | ja（1.00） |
| Nivlet 截图与标注：支持矩形和箭头 | zh-Hans（1.00） |
| OK | pl（0.29），不可靠 |
| 확인 | ko（1.00） |

规则：含汉字或假名的文本按识别结果（中文 → 英语，日语等 → 简体中文）；拉丁字母等其他文本置信度低时按英语处理，译成简体中文。用户在窗口里手动改过的方向按原文语言记住。
