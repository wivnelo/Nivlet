## 使用说明

### 剪贴板

在“设置 → 剪贴板”启用并保存，再复制新内容。点击菜单栏剪贴板图标查看历史：图片在上、文字在下；图片有缩略图及悬停预览，文字前显示 T 方框。设置页历史仍按时间混排。

| 操作 | 方法 |
| --- | --- |
| 复制历史 | 点击菜单中的条目，再到目标应用粘贴 |
| 直接粘贴 | 按住 Option 点击条目，粘贴到打开菜单前的应用；需要辅助功能权限 |
| 搜索 | 菜单“搜索历史…”或设置页历史搜索框；支持文字，不支持图片 OCR |
| 放大图片 | 点击设置页图片缩略图，或聚焦后按 Enter / Space；按 Esc，或点击 Nivlet 窗口内图片框外区域关闭 |
| 停止记录 | 关闭“启用剪贴板历史”并保存；重新开启后只记录新复制的内容 |
| 清空 | 菜单或设置页“清空历史…”；确认后删除历史和缓存，**同时清空系统当前剪贴板，无法撤销** |

文本默认最多 50 条，可选 10–100 条；保留时间默认 30 分钟，可选 30 分钟、1/2/4/8/12/24 小时或永久。永久仍受数量上限限制。图片最多 10 张，每张约 10 MiB；文件复制不记录，图片粘贴需目标应用支持。

默认退出后不保留历史。“跨重启保留历史”需单独启用，缓存为本地明文。重复内容会移到最新位置，不补录启用前或关闭期间的内容。复制敏感内容前可关闭历史记录并保存；应用排除和过滤不能识别所有敏感信息。

菜单快捷键提供一个启用开关，显示为 **⌘⇧ + V**，实际固定组合为 **⌘⇧V**；新安装或缺失快捷键配置时默认开启，明确关闭会跨重启保留。已有自定义组合在启动及修改其他设置时继续保留；实际切换这个开关并保存时，开启使用 ⌘⇧V，关闭解除绑定。菜单快捷键与历史记录总开关相互独立，关闭记录后仍可打开已有历史。

放大图片预览不再使用独立打开或关闭按钮，直接由缩略图打开。关闭范围是 Nivlet 窗口内图片元素框外的区域；图片框内的透明像素仍属于图片，点击不会关闭。关闭点击不会传递给下层控件，Esc 和关闭后的焦点恢复仍保留，包括历史异步刷新后的恢复，不使用全局鼠标监听权限。

### 窗口管理与应用启动

在对应设置页启用功能并配置组合键，然后保存。支持字母、数字、方向键、Return、`=` 和 `-`，字母统一大写显示；可直接录入组合键，输入框旁显示完整组合（例如 `⌃ ⌥ K`、`⌘ ⇧ ←`）。Backspace 或 Delete 清空按键，保留已选修饰键；Tab 移动焦点，Esc 结束录入。录入和清除后立即更新草稿标记、保存状态及冲突提示。默认不预设快捷键。

窗口管理提供半屏、四角、居中、三分区、九宫格、宽高每次增减 40 点及相邻屏幕移动。恢复操作回到本次运行首次调整前的位置。全屏窗口不支持，应用最小尺寸可能限制小格布局；没有相邻屏幕时不会循环移动。

应用启动规则会启动应用或切换到前台。重复添加同一应用会提示并定位已有条目；输入法及浏览器来源规则也会检查重复应用。Nivlet 内快捷键冲突会阻止保存，但无法检测全部第三方快捷键占用。

### 浏览器分流

1. 在“设置 → 浏览器”选择“未匹配时使用”的浏览器，添加域名或来源应用规则。
2. 启用并保存，在其他应用点击链接验证分流；设置页不含内部规则测试区。
3. 点击“设为默认浏览器…”并完成系统确认，再点“重新检测”。若未出现确认，使用“打开默认浏览器设置…”选择 Nivlet；取消接管时改回原浏览器。

匹配顺序为 **域名 → 来源应用 → 默认目标**。域名按列表从上到下匹配，支持子域名选项及 ↑ / ↓ 排序。支持已安装的 Safari、Chrome、Firefox、Edge 和 Brave。网页分流处理 HTTP/HTTPS；2.0.0 另外支持本机 `.html`/`.htm` 交给配置的默认目标浏览器，不按域名或来源应用规则分流。本地 PDF、TXT、图片、XHTML 及 `.url`/`.webloc` 内容解析不在新增范围，`mailto:`、`tel:` 等仍交对应系统应用。部分应用不提供可识别的来源，此时按域名或默认目标处理。

### 系统信息与输入法

在“系统信息”选择需要显示的网速、CPU、内存、磁盘、IPv4、IPv6、公历/星期及农历，保存后生效。设置页显示当前状态；隐藏网速后仍保留信息入口。地址和日期可点击复制。

在“输入法”添加应用并为其选择已启用的系统输入法，启用并保存；下次切到该应用时生效，未配置的应用保持当前输入法。

### 外观、导航与配置

- 语言支持“跟随系统 / 简体中文 / English / 繁體中文 / 日本語”，外观支持“跟随系统 / 浅色 / 深色”。繁体采用台湾用语；香港语言环境回退到繁体中文，不是独立港式本地化。默认跟随系统。原生菜单资源按 macOS 启动时选择的语言加载；Nivlet 内的语言偏好不会强制 AppKit 菜单或 Sparkle 系统对话框立即切换。
- 主图标可显示或隐藏，剪贴板和系统信息入口独立保留。目标排列为“网速 → 剪贴板 → N”，位置也受 macOS 保存的状态影响。
- 左侧边栏选择八个设置页，右侧显示内容。导航项可拖动排序；“通用”固定最上、“关于”固定最下。排序自动保存，其他可编辑设置使用右下角“保存全部设置”。
- “登录 Mac 时自动启动”保存后生效。可选 Command + L 睡眠默认关闭；启用会覆盖浏览器地址栏等应用的同名快捷键。
- 在“通用 → 配置备份与迁移”导出 JSON 或默认示例。导入时先核对替换范围，未包含模块保持不变，失败恢复原配置。历史、缓存、权限、登录项及系统默认浏览器不随配置导出。详见 [配置说明](CONFIGURATION.md)。


### 保存、取消与软件更新

已修改页面在侧边栏显示橙点。“保存全部设置”与 ⌘S 一次提交所有已修改页面，即使当前页未改或停留在关于页也可保存；先完成整体校验，未修改页面不被覆盖。错误会保留相关草稿并定位，运行时部分失败不会伪装为全部成功。“取消当前页修改”只恢复当前页，其他页面草稿保留；切换页面保留草稿。规则拖动排序仍在保存后生效。

在“关于 → 软件更新”手动检查。发现新版本后确认下载并安装、重启；有未保存修改时先处理草稿。当前默认不后台检查或静默安装；检查和下载会联网，配置与剪贴板历史不因此上传。旧 ad-hoc 版首次迁移可能需要重新授权；权限延续以对应版本的实际验收为准，回通用页重新检测。较旧版本没有应用内更新时，从 GitHub 下载新版覆盖安装。

### 剪贴板记录与历史保留

- 关闭记录：保存后停止采集，保留已有文本和图片，可继续搜索、复制、预览及清空。关闭状态跨重启保存。
- 不再提供独立的暂停/恢复操作；历史记录总开关是唯一采集开关。
- 历史始终受容量和保留时间限制；关闭后访问历史仍会清理过期项。启用时不会补录关闭期间的当前剪贴板。
- 跨重启保留开启时，关闭记录后缓存仍保留；未开启时退出后历史不再保留。关闭跨重启保留会移除磁盘缓存，但本次运行的历史仍可用。
- 清空历史是独立的确认操作，会删除历史与缓存并清空系统当前剪贴板。

## 长规则列表

输入法、应用启动、浏览器域名和来源应用列表提供顶部搜索与添加栏。可按应用名、Bundle ID、域名或当前浏览器/输入法名称筛选，搜索不显示数量。长列表滚动时，工具栏保持在该列表顶部；没有匹配时给出空状态。

搜索仅影响显示，不修改配置、顺序或保存范围；保存包含被隐藏的规则。筛选时暂时禁用拖动及域名上下移动，清除搜索后恢复。添加入口会先清除筛选；重复应用会清除筛选并定位原条目。编辑中的条目不会因文字变化突然隐藏，离开后重新筛选。取消修改恢复完整已保存规则，搜索词作为临时界面状态保留。

## 剪贴板页面

记录设置区域顶部显示实际运行状态：正在记录或未启用；切换历史总开关但尚未保存时，运行状态不会提前变化。独立暂停/恢复控件已移除。记录图片、跨重启保留、文本数量和保留时间集中在常用设置，菜单快捷键仅保留启用开关；隐私与应用排除区域保持原有功能。

历史区域的搜索、刷新和清空入口位于列表顶部，不显示搜索数量。无历史、关闭且无历史、搜索无匹配分别提示。复制、图片预览、刷新及清空的结果在历史区域反馈；成功短暂显示，错误保留。宽窗口保留左右独立滚动，窄窗口沿用整页滚动。历史过期后清空按钮同步更新；清空仍沿用原有确认流程，并会清空系统当前剪贴板。

## 操作提示

窗口页使用“默认关闭。快捷键留空表示不绑定。”；统一说明所有布局分组一起保存。菜单快捷键、输入法生效时机、系统信息显示、浏览器测试、应用启动、更新确认和退出保存说明均缩短并同步英文。隐私、明文缓存、历史保留、导入覆盖及清空不可撤销等必要说明保留；导入覆盖、清空历史等确认语义保留。

## 键盘操作

- Tab / Shift-Tab 按页面顺序移动，弹窗中保持在弹窗控件内；方向键可切换侧边栏页面。
- ⌘S 保存所有已修改页面，与右下角“保存全部设置”一致；弹窗或导入预览中不越过确认。
- 快捷键输入框中，⌘S、⌘W、⌘Q 优先录为组合键，不保存、关闭或退出。Esc 离开录入。
- Esc 关闭图片预览和未保存提示并返回原控件；导入预览中取消本次导入。


## 应用规则

- 浏览器页移除内部规则测试。保存后，在其他应用点击链接验证分流；应用与域名规则仍上下分区。
- 应用启动、输入法、浏览器来源应用和剪贴板排除列表使用统一应用图标；拖动图标调整整行顺序，保存后生效。筛选中的规则不能拖动；缺失应用使用占位图标，已有 ID 保留。
- 通过“添加应用…”新增的应用置于列表顶部；重复添加定位原项，不调整原项顺序。读取已有设置与取消修改保持已保存顺序。
- 窗口与应用启动的快捷键字段保持对齐。剪贴板页移除“如何使用剪贴板菜单”说明折叠区；菜单点击复制和 Option（⌥）点击粘贴的实际功能保留，直接粘贴仍需辅助功能权限。
- 中文界面的系统简体拼音显示“简体拼音”；ABC 与第三方输入法保留提供的名称。匹配和切换仍使用原输入源 ID；本轮没有新增第三方兼容性承诺。


后续源码统一按 macOS 提供的应用显示名称展示（去掉 `.app`），不随 Nivlet 界面语言强制翻译；已有规则重新加载后也使用该名称，缺失应用保留旧名或 Bundle ID。

## 界面一致性

折叠标题统一箭头尺寸、间距及展开方向；应用排除的添加按钮保持右对齐。侧边栏统一选中状态、图标和未保存橙点，右侧分组保持可读。底部保存栏在正常状态保持固定高度，操作反馈与按钮位置稳定。通用页仅移除主图标开关下方的说明行，开关本身仍可使用。

### 清除浏览数据与重新唤起

浏览器页右上角点击“清除浏览数据…”，权限检查通过后选择已安装的 Safari、Chrome 或 Brave，在浏览器原生窗口确认清除范围；Nivlet 不自动清除。通过快捷键或 Dock 再次唤起时保留已打开的设置页，首次打开进入通用。

### 保持唤醒与屏幕长亮

通用页的“保持唤醒”和“保持屏幕长亮”默认关闭，使用“保存全部设置”生效。先启用保持唤醒才可选择屏幕长亮；关闭总开关也会关闭子开关。只启用保持唤醒时，屏幕仍可按系统设置熄灭；屏幕长亮额外防止闲置熄屏，可能推迟依赖熄屏的锁定。关闭总开关或退出只释放本应用持有的保活，不修改永久电源/安全设置，不调节亮度或绕过密码。

浏览器的三个原生选择框旁显示选中项真实图标；名称、图标和清理能力来自统一的已安装浏览器信息，切回应用或进入页面时刷新，保留未保存草稿。2.0.1 移除 MAC 地址及其显示开关，其他网络信息与接口选择不变。
