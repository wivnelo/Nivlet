Your data stays
on your Mac.

No account. Settings and clipboard history are processed locally and never uploaded. Core tools work offline.

Cleared on quit

Clipboard history is cleared on quit by default. Optional persistence uses a local plaintext cache; turn recording off before copying sensitive content.

Signed and notarized

Every release is Developer ID signed and notarized by Apple. Updates install only after you confirm.

No tracking

This site uses no analytics scripts or tracking cookies. The app goes online only to check for updates or open links.

Up and running in three steps.

  1. 1

    Download

    Get the DMG or ZIP, move Nivlet to Applications and open it.

  2. 2

    Allow access

    Window actions and Option-paste need Accessibility permission. Never disable Gatekeeper.

  3. 3

    Set it up

    Click the N in the menu bar, open Settings, turn on what you need and click Save All Settings. Browser routing needs Nivlet as the default browser.
